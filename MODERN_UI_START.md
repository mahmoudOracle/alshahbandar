## 🎨 Customization

### **Change Primary Color**
Edit `src/styles/modern.css`:
```css
:root {
  --primary: #3b82f6;  ← Change this to your color
}
```

### **Change Font**
```css
--font-sans: 'Cairo', 'Your Font', sans-serif;
```

### **Adjust Spacing**
```css
--space-lg: 16px;      ← Change base spacing
--space-xl: 24px;
```
