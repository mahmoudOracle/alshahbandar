## 💡 Customization

### **Change Primary Color**
Edit `src/styles/modern.css`:
```css
:root {
  --primary: #3b82f6;  ← Your color here
}
```

### **Change Spacing**
```css
:root {
  --space-lg: 16px;  ← Your size here
}
```

### **Change Font**
```css
:root {
  --font-sans: 'Your Font', sans-serif;
}
```
