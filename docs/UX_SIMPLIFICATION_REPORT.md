# UX Simplification Report

هدف التعديل: جعل الاستخدام "عملي محاسبي بدون تعقيد"، مع التركيز على Dashboard والفواتير والمنتجات/المخزون.

## ما الذي تغيّر
- Dashboard (`pages/Dashboard.tsx`): تبسيط النسخة العربية، إبراز مؤشرات الأداء الأساسية، إبراز أحدث الفواتير، وتحسين حالات الفراغ.
- الفواتير (`pages/InvoiceForm.tsx`): إدخال أسرع على الهاتف مع نصوص واضحة، رسائل تحقق عربية، وتصحيح مفاتيح الأخطاء لكل بند.
- المنتجات والمخزون (`pages/ProductList.tsx`): توحيد المنتجات والمخزون في صفحة واحدة بنصوص عربية عملية، مع تحكم مباشر في المخزون.
- القائمة الجانبية (`components/Sidebar.tsx`) والمسارات (`src/routes.ts`): توحيد التسميات العربية وإزالة ازدواجية مسارات المخزون.

## قبل/بعد تدفق الاستخدام (5 نقاط)
1) قبل: عنوان الملخص غير واضح وحالات فراغ مربكة. بعد: ملخص بسيط + مؤشرات واضحة + حالات فراغ عملية.
2) قبل: إدخال الفاتورة يحتوي نصوص غير مقروءة ورسائل خطأ غير واضحة. بعد: نموذج عربي واضح ورسائل تحقق مباشرة.
3) قبل: المنتجات/المخزون موزعة بمسارات مكررة. بعد: صفحة واحدة للمنتجات والمخزون.
4) قبل: التسميات في القائمة/المسارات غير موحدة. بعد: عناوين عربية موحدة ومختصرة.
5) قبل: تجربة الهاتف أقل وضوحًا في الفاتورة. بعد: إدخال البنود أسرع مع نصوص مختصرة.
